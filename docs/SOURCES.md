# NASA references and factual provenance

This file is a transparent starting reference list for the three missions highlighted in the ASTROMIND pitch. The mission summaries are educational paraphrases and should be reviewed against the original NASA sources before public publication.

## Primary mission references

| Subject | Key point in ASTROMIND | NASA reference |
|---|---|---|
| Apollo Lunar Roving Vehicle | The Apollo crew used a rover to explore beyond their landing site | [NASA — Apollo 17](https://www.nasa.gov/mission/apollo-17/) |
| Sojourner / Mars Pathfinder | Sojourner was the first rover to operate on Mars | [NASA Science — Mars Pathfinder](https://science.nasa.gov/mission/mars-pathfinder/) |
| Opportunity | Designed for roughly 90 sols and operated for nearly 15 years; provided evidence for ancient Martian water | [NASA Science — Opportunity](https://science.nasa.gov/mission/mer-opportunity/) |

For exact technical and scientific claims (dates, instruments, distance, context of the discoveries), consult NASA's mission histories and the relevant instrument/science papers. Do not use the team's artwork as a photograph or scientific source.

## Media verification checklist

When adding authentic NASA media to future screens or documents, record:

1. Source page URL, title, NASA ID if present, mission and asset date.
2. Media creator, credit line and licensing/public-use conditions.
3. Distinction between historic NASA photos, concept art, rendered illustrations and team-created artwork.
4. Whether the original image was cropped/edited, with an appropriately labeled caption.
5. Whether the media supports the associated teaching claim.

Don't infer that everything hosted at a NASA domain is automatically free of restrictions, and do not suggest NASA endorses the project.
