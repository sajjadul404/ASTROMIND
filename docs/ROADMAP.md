# Roadmap

ASTROMIND's primary student-facing prototype was designed in Figma. The plan below intentionally distinguishes deliverables in this repository from future enhancements.

## Available in this repository

- [x] Original ASTROMIND start-screen screenshot
- [x] Original Team Orbit Smiths poster
- [x] 240-second pitch PDF included in the project
- [x] Public Figma prototype URL referenced in README and website
- [x] NASA mission references for Apollo Lunar Rover, Sojourner and Opportunity
- [x] Responsive GitHub Pages companion website
- [x] A small companion website quiz and a three-mission switcher
- [x] Deployment and source-usage notes
- [x] Automated local repository checks

## Highest-priority checks before submission

- [ ] Confirm the Figma URL is publicly viewable and all intended interactions work
- [ ] Confirm final spelling of team names (PDF and poster disagree)
- [ ] Decide whether video footage shows an actual click-through or only an animation/mockup
- [ ] Resolve the API placeholder in the pitch script accurately
- [ ] Check media attribution and rights before adding NASA footage to the video
- [ ] Test GitHub Pages site on desktop and mobile

## Future enhancements

- [ ] Export more Figma screens, with captions, into `assets/images/screens/`
- [ ] Integrate NASA Image and Video Library API and display attribution for each photo
- [ ] Add Moon Trek and Mars Trek map layers for selected landing sites
- [ ] Add PDS-backed scientific context with verified mission citations
- [ ] Build a production game/application beyond Figma
- [ ] Add audio/captions/localization and accessibility review
- [ ] Run small student usability and learning-outcome tests
- [ ] Include a documented lesson plan and educator handout

## Evidence standard

Only move an item to “complete” if it can be independently inspected in the Figma prototype, a running application, a dated demo, a source file or a research report. The website's example quiz is not evidence of a fully implemented mobile learning game.
